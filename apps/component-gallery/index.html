Pattern 框架确认跨框架共用的页面布局、区域、槽位与滚动规则；框架组件用于体验真实的 HTML 组件。组件的逻辑身份、Variant、状态、Slots、Token 与验收信息通过每张运行时卡片标题栏右侧的“组件规范”弹窗查看，不再作为另一套视觉画廊。

Pattern 框架

这里展示页面组合契约，而不是新的一组组件。Pattern A–D 的区域顺序、栏宽策略、Titlebar 分段、表面、分割线、滚动与 inset owner、最小窗口和动作槽位，统一来自 pattern-contracts.json；HTML 只执行解析后的同一份规则。
