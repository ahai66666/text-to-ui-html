# Normalize an approved interactive Demo
Record the source project and preserve the original. Write demo-preservation.json listing confirmed content, navigation, state transitions, interaction controls, test actions and expected outcomes. Work in a new project/copy; do not overwrite the original.
Resolve the existing business task and Pattern without changing approved information relationships. Read only current stage resources. Preserve content and behavior in Blueprint/recipes/bindings or independent business modules; reuse registered controls and canonical styles. For arbitrary static or third-party projects this is a deliberate adaptation, not an automatic behavior-preserving converter.
Run normalize-demo.mjs --source <original-project> --project <output-project> --task <task>. It verifies the separate project and preservation record, then uses the strict generator. Check every preservation item in the real browser; record item IDs and passed/failed evidence. A successful build does not complete behavioral acceptance.
